# jt-personal-website

My personal website and living resume — showcasing my work, projects, story, and a little of life beyond the code.

Built with [Next.js](https://nextjs.org), React, TypeScript, and Tailwind CSS as a single-page site.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Build

```bash
npm run build
```
