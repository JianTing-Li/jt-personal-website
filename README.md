## About

I spent most of my mobile engineering career working on the Goldman Sachs Marquee application. My work included production iOS development with Swift, SwiftUI, and UIKit, followed by contributions to the Android codebase using Kotlin and Jetpack Compose. Along the way, I worked across search, market data, content, and financial workflows.

Today, I'm building on that experience through Pursuit's AI Native Program. I'm developing skills in human-centered AI design, LLM application development, AI solution architecture, and iterative product development.

I created this portfolio as a living home for my experience and projects—something more personal and useful than a document that quickly becomes outdated. It gives me space to share not only what I've built, but also how my background and interests shape the way I approach products.

## Built with

- TypeScript
- Tailwind CSS 4
- Netlify Forms

## Run locally

You'll need Node.js 20.9 or newer and npm.

```bash
git clone https://github.com/JianTing-Li/jt-personal-website.git
cd jt-personal-website
npm ci
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
